# Class Mapping — Mock CSS → shadcn + Tailwind tokens

1:1 translation between the classes in `.docs/design/aurora/webapp/styles.css` and the implementation in the repo (shadcn component + Tailwind classes with semantic tokens).

> **Project rule** ([`.claude/ui-components.md`](../../../ui-components.md) — "Design system tokens are immutable"): never hardcode Tailwind colors (`bg-white`, `text-gray-700`, `bg-emerald-600`), never add new tokens to `globals.css`. The classes listed below use **only** tokens generated by `app/globals.css` (Layer 1 brand for explicit decoration, Layer 2 semantic for everything else). If a mockup class **does not appear here** and has no direct equivalent token → apply the collapse policy (Step 3 + Step 5 of [`SKILL.md`](../SKILL.md)). Full inventory in [`available-tokens.md`](./available-tokens.md).

## Score pill (with trend)

`.score-pill` is a number + arrow (↑/↓/→) used in the paciente detail.

```tsx
<span
  className={cn(
    'inline-flex items-baseline gap-1.5 rounded-md px-2 py-0.5 font-mono text-sm tabular-nums',
    rangeColor, // see available-tokens.md
  )}
>
  <span>{score}</span>
  <span className="font-mono text-[10px]">
    {trend === 'up' ? '↑' : trend === 'down' ? '↓' : '→'}
  </span>
</span>
```

Color by range (see [`available-tokens.md`](./available-tokens.md)):

- score ≥ 70: `bg-success-bg text-success`
- 40–69: `bg-warning-bg text-warning`
- < 40: `bg-destructive-bg text-destructive`

## shadcn atoms to have available for the full mockup

This list is verified in the **Step 3.5 (Atom audit)** of [`SKILL.md`](../SKILL.md) against `components/ui/*` before each implementation. Any missing atom is installed via `/shadcn` **before** writing JSX — never improvise custom markup, never edit `components/ui/*` to add variants (composition lives at the call-site).

- `avatar` — used in sidebar, table, comments
- `badge` — status chips
- `tabs` — paciente detail
- `dialog` — delete confirmations
- `sheet` — side drawer (optional, can be implemented as a dialog)
- `skeleton` — loading states
- `tooltip` — hints over score-pill, icons
- `progress` — progress bar by stage (paciente detail)
- `separator` — visual divider between sections

Already installed: `button`, `card`, `checkbox`, `dropdown-menu`, `input`, `label`, `table`.
